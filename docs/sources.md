# Реестр источников

Коды S01–S34 используются в [требованиях учебных модулей](roadmap-guide.md#учебные-модули). Протокол проверки содержания: [критерии G](release-criteria.md).

Дата веб-проверки: 2026-09-05. Этот реестр подтверждает существование, назначение и доступные сведения об источниках, **не полноту проверки содержания всех будущих лекций**. «Текст» означает доступную веб-страницу/спецификацию; «метаданные» — проверены издатель/описание/оглавление, но главы ещё предстоит получить и прочитать. Ссылка источника в модуле — направление поиска, а не сертификат готовности. S09/S10 особенно не заменяют специализированную библиографию каждого сообщества.
