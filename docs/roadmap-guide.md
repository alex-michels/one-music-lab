# Как пользоваться Roadmap

[ROADMAP](../ROADMAP.md) — единственный реестр выполнения: номер, краткая задача, чекбокс. Нажмите название задачи, чтобы открыть требования. Например: «Выполни пункт №003» или «Проверь готовность №544». Номера — идентификаторы задач, не порядок обязательного изучения.

## Нумерация и статусы

- Нумерация сквозная, с ведущими нулями: 001–714. При перестановке задачи номер сохраняется. Новые задачи получают следующий свободный номер после максимального; прежние номера не переиспользуются.
- `[x]` ставится только за проверенный результат в принятом PR; `[ ]` означает, что работа или приёмка не завершена. При регрессии пункт открывается повторно со ссылкой на issue в документе доказательств.
- Учебный пункт закрывается только целиком по [G](release-criteria.md): теория, лаборатория, практика, энциклопедия и общие проверки. Промежуточные доказательства хранятся в спецификации, без второго списка статусов.
- Готовность модуля следует из выполнения его учебных пунктов по G. Фактическая публикация имеет собственный номер и требует отдельного разрешения владельца; [правила и связи](releases.md).
- Исходные 511 ID тем и 128 кодов модулей сохранены ниже как постоянные алиасы. P00–P10 обозначают прежние инженерные группы; `/1`, `/2` и т. д. — позиции пунктов внутри группы до переноса. Для новых поручений используйте номер из Roadmap.
- Не заменяйте доказательства историческим аудитом: наблюдения, принятые PR и незавершённые требования могут иметь разные даты. При этой реорганизации все 511 учебных тем и 128 публикаций остались открытыми; инженерные статусы перенесены без изменений.
