# Публикация учебных модулей

Статус публикации ведётся отдельным пунктом в [ROADMAP](../ROADMAP.md). Завершение темы по G не означает её публикацию. Для каждого модуля сначала закрываются его учебные пункты и применимые инженерные требования, затем требуется отдельное разрешение владельца на публичное размещение. До этого действует [режим закрытого стенда](private-staging.md).

Доказательства выпуска: принятый PR, commit, версия, дата, URL, проверенный артефакт и способ отката. Пустой шаблон доказательств в спецификации не означает готовность.
