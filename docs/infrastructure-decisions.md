# Инфраструктура, CI/CD и экономическая модель

Датированные решения и рекомендации перенесены из аудита 2026-09-05; цены и характеристики не проверялись повторно при реорганизации 2026-09-07. Текущие задачи: [ROADMAP](../ROADMAP.md), ограничения размещения: [private staging](private-staging.md), источники: [реестр](sources.md).

**Рекомендация на старт: небольшой Linux VPS в ЕС, статические файлы через Caddy, вычисление звука в браузере.** Практичный кандидат — Hetzner Cloud класса CX23; начать с порядка 2 vCPU / 4 GiB RAM, подтвердив конфигурацию при заказе. Сборку выполняет GitHub Actions, поэтому серверу не нужны тяжёлый build toolchain, GPU или аудиосервер. Если подходящий VPS уже есть, дополнительный пока не нужен. Это рекомендация под небольшой стартовый трафик, а не гарантия производительности без измерений.

На проверенной странице Hetzner действует цена **CX23 €5.49/месяц без VAT и IPv4** для указанных EU-локаций; новые цены вступили в силу 15 июня 2026. Домен, IPv4, backup и возможное хранилище оплачиваются отдельно; окончательный бюджет сверить в корзине. Не опираться на устаревшие статьи с более низкой ценой [S26]. У Caddy есть автоматическая выдача/продление TLS при корректном DNS и доступности необходимых портов [S27].

| Вариант | Когда подходит | Решение сейчас |
|---|---|---|
| Собственный EU VPS + Caddy | Нужен контроль сервера, переносимость, будущий небольшой API | Рекомендуемый путь после P04 |
| Managed static hosting/CDN | Приоритет — минимум администрирования, статическая публичная библиотека | Допустимая альтернатива; менее соответствует пожеланию о собственном сервере |
| Node SSR + БД + object storage | Реально появились серверные сессии, кабинеты, платная синхронизация | Отложить до подтверждённой потребности; отдельный deploy/backup план |

Текущий проект собирается под Worker/Sites. Корневой `dist` нельзя считать готовым веб-каталогом для Caddy без проверки. Vinext документирует static export и standalone Node, поэтому сначала проверяется переносимость текущего проекта. Astro с React islands — резервный вариант для большого статического корпуса лекций, если это даст подтверждённые преимущества URL, индексации и размера клиентского кода. В этом аудите миграция и production deploy не выполнены [S23, S24].

CI для PR: фиксированные зависимости (`npm ci`), минимальные permissions, SHA-pinned actions, тесты, typecheck, lint, schema/content проверки и build; в полной версии — coverage и browser suite. Deploy выполняется отдельным workflow после merge/release по решению владельца, с secrets только в доверенном Environment. Не исполнять недоверенный PR с `pull_request_target` и deploy credentials. GitHub-hosted runner предпочтительнее self-hosted runner на production VPS для внешних PR [S25].
